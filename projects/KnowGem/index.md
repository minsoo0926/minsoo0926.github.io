## Overview

KnowGem is a focused workspace to connect concepts from documents, visualize
their relationships, and validate formal logic in one place. The goal is to
enable hallucination-free, deductive reasoning by grounding LLM outputs in an
editable, symbolic knowledge graph.

## Features

- **Structured context.** Unify scattered sources into a single graph context
  that is easy to navigate in real time.
- **Interactive graph visualization.** Inspect and edit complex relationships
  between concepts with interactive graph tools.
- **Formal validation.** Validate reasoning outputs with Higher-Order Logic
  (HOL) expressions to support evidence-based decisions.

## Technology

- Backend: Express.js, Supabase (PostgreSQL)
- Frontend: React
- Cloud: AWS
- Infrastructure: Terraform, GitHub Actions
