## Overview

End-to-end data parsing, reinforcement-learning environment, and macro tool
for the KakaoTalk Gamebot game *검키우기* (Sword Growing). Includes a
Gym-compatible environment for training agents and an automation layer for
repetitive in-game tasks.

## Technology

- RL framework: stable-baselines3, gymnasium, tensorboard
- I/O for macro: pyautogui, pynput
